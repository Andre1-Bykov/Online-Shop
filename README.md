# Guitar Shop

Онлайн-магазин гитар и музыкальных инструментов, реализованный как статический веб-проект на HTML, CSS и JavaScript. Проект позволяет просматривать каталог товаров, фильтровать и сортировать их, добавлять в корзину и оформлять заказ.

## О проекте

Guitar Shop — это учебный интернет-магазин с простым и понятным интерфейсом. Пользователь может:

- просматривать каталог гитар;
- искать товары по названию;
- фильтровать по типу и бренду;
- сортировать по цене и имени;
- добавлять товары в корзину;
- изменять количество товаров в корзине;
- видеть итоговую сумму заказа;
- сохранять выбранные товары в `localStorage` браузера.

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- JSON для хранения каталога товаров
- Local Storage для сохранения корзины

## Как запустить проект

1. Склонируйте репозиторий:

```bash
git clone https://github.com/Andre1-Bykov/Online-Shop.git
```

2. Перейдите в папку проекта:

```bash
cd Online-Shop
```

3. Откройте файл `online_shop/index.html` в браузере.

Для более удобного локального просмотра можно использовать Live Server или любой локальный HTTP-сервер.

Пример через Python:

```bash
cd online_shop
python -m http.server 8000
```

После этого откройте в браузере адрес:

```text
http://localhost:8000
```

## Основные страницы

- `index.html` — главная страница с каталогом и фильтрами
- `cart.html` — страница корзины с итоговой суммой
- `presentation.html` — отдельная страница с презентацией проекта

## Функциональность

### Каталог товаров

На главной странице пользователь видит карточки товаров с:

- названием;
- изображением;
- описанием;
- характеристиками;
- ценой;
- кнопкой добавления в корзину.

### Поиск и фильтрация

Поддерживаются:

- поиск по названию товара;
- фильтрация по типу гитары;
- фильтрация по бренду;
- сортировка по имени и цене.

### Корзина

Корзина хранится в браузерном `localStorage`, поэтому данные сохраняются между перезагрузками страницы.

В корзине можно:

- увеличить или уменьшить количество товара;
- удалить товар;
- увидеть итоговую сумму;
- подтвердить заказ.

## Примечание

Этот проект является статическим веб-приложением и не требует установки зависимостей или серверной части. Он подходит для демонстрации работы интернет-магазина, обучения frontend-разработке или как базовый шаблон для дальнейшего развития.
